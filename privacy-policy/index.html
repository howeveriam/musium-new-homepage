Musium Zoom YouTube Uploader가 Zoom 클라우드 녹화를 지정 YouTube 채널로 전송하는 과정에서 어떤 정보를 다루고, 왜 보관하며, 어떻게 보호하는지 설명합니다.

핵심만 먼저

원본 그대로 전송: Zoom의 녹화 원본과 필요한 메타데이터를 가져와 추가 압축·재인코딩 없이 업로드합니다. 미등록 공개: 영상은 운영자가 지정한 YouTube 채널에 '일부 공개(Unlisted)'로 생성됩니다. 자동화를 위한 보관: OAuth 토큰과 업로드 기록은 Muse 클라우드 서버에 저장됩니다.

01. 이 방침이 적용되는 범위

이 방침은 Musium Zoom YouTube Uploader(이하 "업로더")의 자동 녹화 전송 기능과 그 운영을 위해 사용하는 서버에 적용됩니다.

업로더는 승인된 Zoom 계정의 클라우드 녹화를 확인하고, 새 녹화의 원본 MP4 파일을 운영자가 지정한 YouTube 채널에 일부 공개로 올립니다. 업로더는 불특정 이용자를 대상으로 하는 소셜 서비스가 아니며, 승인된 계정과 채널 사이의 전송을 자동화하는 운영 도구입니다.

이 페이지 자체는 입력 폼, 광고 추적기 또는 자체 쿠키를 사용해 방문자의 개인정보를 수집하지 않습니다. 외부 링크를 선택하면 해당 서비스의 정책이 적용됩니다.

02. 처리하는 정보

업로더는 기능 제공에 필요한 범위에서 다음 정보를 처리합니다.

Zoom 녹화 콘텐츠 클라우드에 저장된 녹화 원본 MP4의 영상·음성. 녹화에 참여자의 얼굴, 목소리, 화면 공유 및 수업 내용이 포함될 수 있습니다.

Zoom 메타데이터 회의 또는 녹화 제목, 회의 ID, 녹화 파일 ID, 녹화 시각, 파일 형식과 크기, 다운로드 상태 등 녹화를 식별하고 전송하는 데 필요한 정보.

Google·YouTube 정보 OAuth 액세스·갱신 토큰, 승인된 YouTube 채널 식별자, 업로드한 영상의 ID·링크·공개 상태, 업로드 처리 결과와 API 오류 정보.

업로드 기록 `zoom:<파일 ID>` 형식의 중복 방지 식별자, 처리 시각, 성공·실패 상태 및 오류 진단에 필요한 최소 로그.

업로더는 광고 프로필 작성, 신용 평가 또는 데이터 판매를 위해 위 정보를 처리하지 않습니다.

03. 처리 방식과 목적

1. 승인된 Zoom 계정 확인: Zoom 인증을 사용해 새 클라우드 녹화 목록과 메타데이터를 조회합니다. 2. 중복 여부 확인: 녹화 파일 ID를 기존 업로드 기록과 비교해 이미 처리한 파일은 다시 업로드하지 않습니다. 3. 원본 파일 전송: 새 MP4 원본을 Muse 클라우드 서버에서 처리하며, 추가 압축이나 재인코딩 없이 지정 YouTube 채널로 보냅니다. 4. 일부 공개로 설정: YouTube 영상의 공개 상태를 일부 공개(Unlisted)로 지정합니다. 링크를 가진 사람은 영상을 볼 수 있으므로 링크 관리가 필요합니다. 5. 결과 기록과 검증: 영상 ID, 링크, 상태와 처리 결과를 기록해 중복 업로드를 방지하고 오류를 확인합니다.

Google API 데이터에 관한 약속

업로더가 Google API로부터 받은 정보를 사용하거나 다른 앱으로 전송하는 방식은 Google API Services User Data Policy 및 그 제한적 사용(Limited Use) 요구사항을 준수합니다.

Google 사용자 데이터는 위 자동 업로드 기능을 제공하고 보안을 유지하는 목적에만 사용하며, 광고·데이터 판매·범용 AI/ML 모델 학습에 사용하지 않습니다.

04. 보관 기간과 삭제

작업용 녹화 사본 Zoom 원본은 YouTube 전송, 업로드 완료 확인 및 장애 복구에 필요한 기간 동안 Muse 클라우드 서버의 작업 공간에 보관될 수 있습니다. 목적을 달성해 더 이상 필요하지 않은 작업용 사본은 운영 과정에서 삭제합니다. Zoom과 YouTube에 남는 원본·업로드본은 각 서비스의 보관 설정과 삭제 정책을 따릅니다.

OAuth 토큰 Zoom 및 Google/YouTube OAuth 토큰은 자동 실행을 유지하는 동안 서버에 보관합니다. 계정 연결이 해제되거나 업로더 사용이 종료되면, 법적·보안상 보관이 필요한 경우를 제외하고 서버의 토큰을 삭제합니다.

업로드 기록 업로드 기록은 중복 업로드 방지, 상태 확인 및 장애 대응에 필요한 동안 보관합니다. 운영 목적이 끝나거나 삭제 요청이 확인되면 관련 기록을 삭제 또는 식별 불가능한 형태로 정리합니다.

05. 서비스 제공자와 국외 처리

업로더는 자동 전송 기능을 수행하기 위해 아래 서비스와 정보를 주고받습니다. 개인정보를 판매하지 않으며, 맞춤 광고를 위해 제3자에게 제공하지 않습니다.

Zoom: 승인된 계정의 클라우드 녹화 원본과 메타데이터를 제공하는 출처입니다.

Google / YouTube: 승인된 채널 확인, 원본 영상 업로드, 일부 공개 설정 및 업로드 결과 확인을 처리합니다.

Muse 클라우드 인프라: 업로더 코드가 실행되고 OAuth 토큰, 작업용 파일 및 업로드 기록이 보관되는 서버 환경을 제공합니다.

위 사업자는 서버 위치와 운영 구조에 따라 이용자의 거주 국가 밖에서 정보를 처리할 수 있습니다. 각 사업자의 처리에는 해당 사업자의 약관과 개인정보 보호 문서가 함께 적용됩니다.

06. 정보를 보호하는 방법

OAuth 토큰과 계정 설정 파일을 공개 페이지 및 배포용 설치 파일과 분리해 서버의 제한된 경로에 보관합니다. 토큰, 비밀키 및 인증된 다운로드 주소가 일반 알림이나 공개 로그에 노출되지 않도록 운영합니다. 전송 과정에서는 Zoom과 Google/YouTube가 제공하는 암호화된 연결을 사용합니다. 기능 수행에 필요한 최소 권한만 사용하고, 업로드 기록을 이용해 같은 원본의 중복 처리를 방지합니다. 오류 로그와 접근 권한을 점검하고, 의심스러운 접근 또는 보안 사고가 확인되면 연결 해제와 토큰 폐기 등 필요한 조치를 취합니다.

어떠한 전자적 보관·전송 방법도 절대적인 안전을 보장할 수는 없지만, 정보의 성격과 위험에 맞는 합리적인 보호 조치를 적용합니다.

07. 이용자의 선택과 권리

계정 소유자와 관련 정보주체는 적용 법률이 허용하는 범위에서 개인정보 처리 내역의 확인, 정정, 삭제, 처리 제한 또는 동의 철회를 요청할 수 있습니다.

Google 연결 해제 Google 계정의 보안 설정에서 업로더의 접근 권한을 언제든 철회할 수 있습니다. 접근 권한을 철회하면 새 영상 업로드와 기존 업로드 상태 확인이 중단됩니다. 서버에 저장된 토큰과 업로드 기록의 삭제도 별도로 요청할 수 있습니다.

Zoom 연결 해제 Zoom 계정에서 업로더의 권한을 해제하거나 연결 정보를 폐기하면 새 녹화 조회와 다운로드가 중단됩니다. 연결 해제 전에 이미 YouTube로 전송된 영상은 자동으로 삭제되지 않으며, YouTube 채널에서 별도로 관리해야 합니다.

녹화 참여자에 대한 책임 회의 또는 수업을 녹화하고 업로드하는 운영자는 참여자에게 녹화 사실과 이용 목적, 일부 공개 링크의 공유 범위를 알리고 필요한 동의를 받아야 합니다. 특히 아동이 포함된 경우 적용되는 보호자 동의 및 관련 법적 의무를 확인해야 합니다.
